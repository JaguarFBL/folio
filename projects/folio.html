Folio

Portfolio interactif — HTML/CSS/JS pur, zéro dépendance

Contexte

Besoin d'un portfolio en ligne pour présenter mes projets de design et développement. Contrainte : zéro build step, hébergé sur GitHub Pages, compatible mobile et desktop.

Approche

HTML/CSS/JS vanilla, sans framework ni bibliothèque. Glassmorphism épuré, grille de scanlines, overlay fumée, stickers technos draggable avec physique (gravité, collision, throw). Curseur personnalisé avec lerp, hamburger menu responsive, cassette décorative.

Résultat

Un site léger, rapide, responsive, avec une identité visuelle forte. Les stickers animés et le curseur custom offrent une expérience interactive inattendue pour un portfolio classique.

Détails techniques

Développé en HTML/CSS/JS pur avec hébergement GitHub Pages. Le système de stickers utilise un moteur physique maison (gravité 0.15, friction 0.94, répulsion curseur, désactivation overlap). Le curseur custom utilise un lerp fluide avec agrandissement au survol des éléments interactifs.

Design responsive avec un breakpoint à 768px : menu hamburger, empilement vertical, masquage de la cassette sur mobile. Le thème monochrome avec accents glassmorphism assure une cohérence visuelle sur toutes les pages.
